# Домашні роботи з Embedded

Навчальні проєкти для ESP32-S3 на Arduino та PlatformIO.

| Завдання | Проєкт | Тема |
| --- | --- | --- |
| 1.5 | [Лічильник натискань](homework-01-05-button-interrupt-counter/) | GPIO-переривання та виведення лічильника в Serial |
| 1.6 | [Фоторезистор із гістерезисом](homework-01-06-photoresistor-hysteresis/) | АЦП та керування виходом за двома порогами |
| 2.1 | [Неблокуюче блимання LED](homework-02-01-nonblocking-led/) | Клас C++ та керування часом через millis() |

## Початок роботи

Встановіть PlatformIO Core або розширення PlatformIO для VS Code. Відкривайте папку окремої домашньої роботи як проєкт PlatformIO.

Команди з кореня репозиторію:

```sh
pio run -d homework-01-05-button-interrupt-counter
pio run -d homework-01-06-photoresistor-hysteresis
pio run -d homework-02-01-nonblocking-led
```

У кожному проєкті збережено початкову конфігурацію: платформа `espressif32`, плата `adafruit_feather_esp32s3_nopsram`, фреймворк `arduino`. Перед прошиванням перевірте відповідність цілі вашій фізичній платі. Версію платформи в початкових конфігураціях не зафіксовано.

Опис підключення, поведінки та обмежень наведено в README кожної роботи. Номери GPIO позначають сигнали мікроконтролера, а не позиції контактів роз'єму. Вихідний код збережено без зміни поведінки.
