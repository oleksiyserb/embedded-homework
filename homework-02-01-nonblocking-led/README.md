# Домашня робота 2.1 — Неблокуюче блимання LED

Вправа з Embedded C++: клас для керування світлодіодом і перемикання через `millis()` без `delay()`.

## Підключення

GPIO 15 керує LED з активним високим рівнем. Зовнішній світлодіод підключають до GPIO 15 через відповідний струмообмежувальний резистор, із поверненням до GND. Початкова схема та номінал резистора не надані.

## Реалізація

- `include/Led.h` — клас LED і стани `ON`/`OFF` через `enum class`.
- `src/Led.cpp` — налаштування виходу та зміна стану.
- `src/main.cpp` — константи `constexpr` для GPIO та інтервалу, локальна статична змінна часу.
- Під час ініціалізації LED вмикається, потім перемикається кожні 1000 мс. Повний цикл становить приблизно 2000 мс.

Початковий текст завдання збережено в коментарях коду. Реалізація використовує глобальний об'єкт LED і метод `setState()` замість зазначеного в завданні `set()`. Окремої структури конфігурації, вимірювання часу superloop та опційних режимів кнопки через переривання немає. Наявність проєкту в репозиторії не означає виконання всіх пунктів початкового завдання.

## Збірка та прошивання

Виконайте в папці цієї роботи:

```sh
pio run
pio run --target upload
```

Ціль: `adafruit_feather_esp32s3_nopsram`, Arduino, Espressif32. Компіляція успішна; перевірка на фізичній платі під час підготовки репозиторію не проводилася.
