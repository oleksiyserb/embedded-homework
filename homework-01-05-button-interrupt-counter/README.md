# Домашня робота 1.5 — Лічильник натискань через переривання

Програма рахує переривання за спадним фронтом на GPIO 16 та виводить оновлений лічильник у Serial зі швидкістю 115200 бод.

## Підключення

Кнопка з'єднує GPIO 16 із GND. Використано `INPUT_PULLUP`, тому натискання формує спадний фронт.

## Поведінка та обмеження

Обробник переривання збільшує `volatile`-лічильник. Основний цикл виводить значення, коли помічає зміну, і має затримку 10 мс. Кілька переривань між ітераціями можуть відобразитися одним повідомленням зі збільшеним значенням.

Антидребезг не реалізовано: одне фізичне натискання може дати кілька спрацювань. Лічильник рахує переривання, а не гарантовано окремі натискання.

## Збірка та прошивання

Виконайте в папці цієї роботи:

```sh
pio run
pio run --target upload
pio device monitor --baud 115200
```

Ціль: `adafruit_feather_esp32s3_nopsram`, Arduino, Espressif32. Компіляція успішна; перевірка на фізичній платі під час підготовки репозиторію не проводилася.
